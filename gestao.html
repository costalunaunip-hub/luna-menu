Disponibilidade do dia

Esgotados de hoje, itens a esconder por um dia e o aviso do dia fazem-se na folha «Luna Menu - Disponibilidade» (app Google Sheets): muda a célula Estado e o site reflecte em segundos, sem publicar nada. Este editor é para o que dura mais: preços, itens, categorias, horário.

Abrir a folha de disponibilidade

Aviso fixo no topo do menu

Para avisos de longa duração. O aviso do dia da folha tem prioridade enquanto existir. Apague o texto para o retirar.

Horário

Toque num dia para o marcar como encerrado. O rodapé e os dados para o Google são gerados a partir daqui.

Categorias e itens

Toque numa categoria para abrir. Esgotado mantém o item visível, riscado; Oculto retira-o do menu sem o apagar (sazonal). Para um só dia use a folha de disponibilidade. O nome em português é a chave que liga o item à folha: se o mudar, mude também a linha na folha.

    ⚙ Ligação ao GitHub

    Para publicar directamente a partir daqui é preciso um token de acesso pessoal do GitHub (fine-grained), limitado a este repositório com permissão Contents: Read and write. O token fica guardado apenas neste dispositivo (armazenamento do navegador) e pode ser revogado em qualquer altura em github.com → Settings → Developer settings. Sem token, use «Copiar JSON» ou «Descarregar» e substitua o ficheiro menu.json na interface web do GitHub.
